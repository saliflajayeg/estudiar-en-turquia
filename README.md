# Estudiar en Turquía

Web de **Asesoría de Viajes**: buscador de carreras en universidades de Turquía y Chipre (precios en FCFA/USD, idiomas, niveles) y acompañamiento para estudiantes de Guinea Ecuatorial: inscripción gratuita, carta de admisión, visado y recogida en el aeropuerto.

Web estática (HTML/CSS/JS, sin compilación). Datos de programas en `data/programas.js`.

Para verla en local: `iniciar-estudiar-turquia.bat` → http://localhost:3060
